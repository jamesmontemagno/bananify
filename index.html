Download Bananify for Chrome / Edge ↓

  1. Download the ZIP above and extract it.
  2. Open chrome://extensions or edge://extensions.
  3. Turn on Developer mode and choose Load unpacked.
  4. Select the extracted bananify folder that contains manifest.json, then pin Bananify.
  5. Visit a website. Click the banana. Embrace the banana.

Free for desktop Chrome and Edge. More bananas brings a different monkey and transforms more of the page. Restore page brings it all back. This is a manual install, not a browser-store listing; browser settings and extension stores are off-limits.
